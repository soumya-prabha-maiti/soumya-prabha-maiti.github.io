A webapp that uses a **Convolutional Neural Network (CNN)** to predict the disease of a tomato leaf by using the image of a tomato leaf as input.

## Features
- Upload a tomato leaf image and get an instant disease prediction
- Trained on a comprehensive tomato leaf disease dataset
- Containerized with Docker for easy deployment
- Deployed on HuggingFace Spaces

## Tech Stack
| Component | Technology |
|-----------|-----------|
| Model | TensorFlow / Keras CNN |
| Backend | Python + Flask |
| Containerization | Docker |
| Deployment | HuggingFace Spaces |
